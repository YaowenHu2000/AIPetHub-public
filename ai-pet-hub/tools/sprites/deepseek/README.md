# 大肥鱼（DeepSeek 鲸鱼娘）的素材

第四位桌宠。成品在 `web/sprites/deepseek/v2/`：109 张，640×640 RGBA。她没有骨骼版（没有 `web/rig/deepseek/`），所有状态都用逐帧。
这里是重新出图、改图时要用的东西；通用的逐帧流程见上一层的 [README](../README.md)。

形象的来源和署名见仓库根目录的 `ASSETS-LICENSE.md`。参考用的设定图只放在本机的 `ref/`（不入库），只在画母版那一步用过；之后所有动作都只以 `master.png` 为输入。

## 角色设定

深藏青长卷发、发梢渐变蓝；乱一点的刘海，中间一缕落在两眼之间；头顶一根大呆毛；白色荷叶边女仆发带；画面右边一个浅蓝小蝴蝶结；
鲸鳍耳（外藏青内白）；深藏青长袖女仆裙（金色细边、裙上两个小金边蝴蝶结）、白领、白褶边袖口和裙摆；白围裙中间一个蓝色喷水鲸鱼图案；
白袜、深色玛丽珍鞋；身后一条水平尾鳍的鲸尾；2.5 头身，圆脸。画风和另外三位的母版一致（线条、上色、高光）。

母版 `master.png`：1024×1024 透明底，正面自然站立、双手垂着、中性微笑；头顶 y≈59、脚底 y≈998。

## 怎么重新出图

全部走 CPA 反代的生图接口（`tools/rig/imgapi.py`）。12 帧循环 = 两段各 6 帧，每段是一张 3×2 的整图切出来的；两段都从同一张底图起头、回到底图。

1. `gen_master.py` 出母版（三张备选），`fit_master.py` 规格化。
2. `gen_set.py bases`：所有底图、单张、走路整图一次并发发出去，输入只有 `master.png`。
3. `post_set.py pick`：底图下半身对齐到母版。
4. `gen_set.py sheetsA`：各循环前半段的 3×2 整图。
5. `gen_set.py sheetsB`：后半段。压接缝的办法：image 1 给底图，image 2 给已经挑好的前半段整图，要求线条、卷发、大小、格内位置都照 image 2 画。
6. `post_set.py slice`：切格 → 整格平移到底图脚底 → 对齐、统一颜色、钉住头部 → 被画布切到的边渐隐。
   `height` 让整套身高和底图一致；`walk` 按头部对到母版；`single` / `blink` 处理单张和眨眼；`place` 整体平移。最后统一清掉 alpha ≤ 24 的底雾。
7. `check_pos.py` 量各帧头、脚相对 idle 的位置（状态切换时跳不跳）；`preview.py` 出预览图和相邻帧差，放在 `out/`。

`gen_loop.py` 是最早试做思考循环时的脚本，已被 `gen_set.py` 取代。

经验：约四分之一的图要弃用（整张灰底、底雾、特效出格、把「拎着她的手」画出来），所以每一步都出两张备选。

## 这套素材已知的毛病

- **拖拽偏闹**：每帧左右交替，App 里 100 ms 一帧来回播，等于 10 Hz 扑腾。嫌快就在 `web/js/stage/` 的 `STRUGGLE_PICK` 里只挑几帧放慢（吉佩缇是这么做的）。
- **走路**只有 6 张不同的图，是正面原地踏步，不是侧面走；头比 idle 大 2–4%。
- **fast 形态**头发飘到最右 x≈633（640 里），没被切但很靠边。
- 书和键盘上的小字每帧不完全一样（模型每格都重画），小尺寸下看不出。
- 线条比另外三位的 1024 原图略软（每格 512 放大到 640）。
